# TP DevOps : Git & Gestion du Code

Petite application Python de démonstration, réalisée dans le cadre du
TP N°1 du module DevOps (Université Abderrahmane Mira, Béjaïa).

## Objectif
Simuler le cycle de vie du code : création, branches, conflits,
collaboration via GitHub, Pull Request et publication d'une version.

## Lancer l'application
```bash
python3 main.py
```
